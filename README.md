# LLM Public Services Requirements

Экспериментальные материалы к статье «Применение больших языковых моделей в бизнес-анализе государственных услуг» (ИП&УЗ, 2026).

**Статус: полный комплект опубликован в ZIP-архиве.** [Скачать архив экспериментальных материалов (277 файлов)](llm-public-services-requirements.zip). В архиве находятся исходные ответы моделей, итоговая разметка, нормативный корпус, код, инструкция по воспроизведению и контрольные суммы. Распакуйте архив перед запуском программ. В репозитории также доступны три отдельные сводные таблицы.

Replication materials for a study of locally run language models extracting requirements for Russian public services. The pilot and extended experiments are analysed separately. AI-assisted annotations have not been independently validated by human experts.

## Опубликованные таблицы

- [По режимам запроса](extended_analysis/semantic_mode.csv)
- [По моделям и режимам](extended_analysis/semantic_model_mode.csv)
- [По моделям](extended_analysis/semantic_model.csv)

Расширенный эксперимент: 90 запусков (3 модели × 3 услуги × 2 режима × 5 повторов), 31 эталонное правило, 930 оценок соответствия. Итоговая разметка: 127 полных, 322 частичных, 418 отсутствующих правил и 63 противоречия. Все оценки выполнены с помощью ChatGPT; независимой оценки человеком нет. Корпус состоит из нормализованных пересказов нормативных положений. 26 генераций из 90 достигли лимита токенов.

Пилот: 12 запусков; результаты пилота не объединяются с расширенным экспериментом. Условия лицензирования должны быть согласованы правообладателем.
